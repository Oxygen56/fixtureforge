# Evidence policy

Every outward claim maps to a reproducible artifact.

| Claim | Required evidence |
|---|---|
| Autonomous scope | goal interpretation, search, lineage selection, and namespace receipt |
| Source-row-free | MCP trace contains only an allowlisted metadata tool set |
| Deterministic | Two independent builds have identical manifest hashes |
| Relationship-safe | DuckDB foreign-key checks return zero violations |
| Governance-aware | Generated fields cite the tags, glossary terms, and assertions used |
| Git delivery | isolated branch, commit, diff check, and public PR receipt |
| DataHub integrated | Context Document plus full-fingerprint content readback |

Static examples are demonstrations, not proof of live integration. A local
DataHub result is not evidence of production deployment or adoption.
