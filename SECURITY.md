# Security policy

Do not report credentials or private metadata in public issues. For the hackathon
release, use a private maintainer contact listed in the repository security tab.

FixtureForge separates read-only MCP collection from mutation. Mutation is off by
default, writeback is restricted to localhost, and the command requires an
explicit approval flag.

The phrase source-row-free is a narrow implementation claim. It is not a privacy,
anonymization, or compliance guarantee.
